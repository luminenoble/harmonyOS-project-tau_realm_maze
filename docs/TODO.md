## Day 2 — 迷宫生成 & 地图数据结构

**目标：** 实现随机迷宫生成，并在等距视角下正确渲染墙体。

- [ ] 实现 `MazeGenerator.ts`（递归回溯算法，输出二维网格通道数组）
- [ ] 定义瓦片类型枚举：`FLOOR / WALL / VIA / GATE / FRAGMENT`
- [ ] 实现 `TileSet.ts`：各瓦片的 Canvas 绘制方法（几何图形，无需图片资源）
- [ ] 将迷宫数据渲染到等距视图，包含墙体遮挡排序（Painter's Algorithm）
- [ ] 验收标准：随机迷宫每次不同，墙体前后遮挡关系正确

## Day 6 — 动态地图（移动迷宫机制）⚡关键里程碑

**目标：** 每 20 步触发一次地图局部重构，增加紧张感。

- [ ] 在 `MapManager.ts` 中实现步数计数器
- [ ] 设计局部重构算法：随机封闭/开启若干通道（保证地图仍可解）
- [ ] 重构前播放警告动效（红色闪烁 + 提示文字"信号重路由中..."）
- [ ] 重构后播放青绿脉冲动效，新通道高亮显示
- [ ] 确保重构后玩家位置仍合法（玩家所在格不变为墙）
- [ ] 验收标准：动态重构不导致死局，视觉反馈清晰
- [ ] **可选难度强化：等距视角旋转（90° 四档）**
  - 在 `IsoRenderer` 层做坐标预变换（`rotation: 0|1|2|3`），`MapManager` 不感知
  - 玩家输入向量按同样矩阵旋转
  - 配套 ~300ms tween 过渡动画 + HUD 罗盘指示
  - 与动态重构叠加产生方向迷失感；若动态重构难度已足够，可推迟到 Day 8 视觉润色阶段
